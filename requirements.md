# Requirements — Simple Todo App

## What to build
A single-page todo list app.

## Features
- Add a new todo via text input + button
- Mark a todo as complete (strikethrough)
- Delete a todo
- Show count of remaining items
- Persist todos in localStorage

## Tech
- Plain HTML, CSS, JavaScript
- Must work in Chrome without any build step

## Acceptance criteria
- All features work correctly
- No console errors
- Mobile responsive (375px wide)
